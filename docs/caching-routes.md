# Caching the Routes

It is possible to cache the routes generated by `OpenApiRouteList` by passing any PSR-16 instance to `withCache()`:

```php
<?php
$routeDefinition = new OpenApiRouteList(__DIR__ . '/swagger.json'); 
$routeDefinition->withCache(new FileSystemCacheEngine());
```

## The dispatcher

A route list builds its dispatcher (`getDispatcher()`) once, the first time it handles a request, and keeps it until
a route is added (`addRoute()`, `setRoutes()`, `addClass()`). A route list that lives across requests (a DI
singleton in a persistent worker, or in tests) does not rebuild it on each request.

Only the method and the path of each route are compiled, and they cannot change. The output processor, the class
and the metadata of a route are read when a request matches it, so a route changed afterwards is used as it is now:

```php
<?php
$routeDefinition->getRoute('GET', '/item/{id}')->withOutputProcessor(XmlOutputProcessor::class);
// The next request to GET /item/{id} uses XmlOutputProcessor
```
